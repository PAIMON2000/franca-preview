# Franca 当前品牌图片

`franca-pixel.png` 是本轮通过内置图像生成工具制作并由用户选定的像素风格 PNG，作为 WPF Resource 嵌入程序。保留透明通道，固定蓝发、静态展示，不随主题变色。它是位图素材，不是 SVG，也未按固定尺寸逐像素精修；地图为风格化示意，不作为地理精度资料。

最终生成提示词以第二版角色为身份参考，以用户提供的地图中心部分为投影构图参考，要求头部、闭眼表情、A/中发卡、头部与地图大小接近、像素风、透明背景，去除外部文字和装饰。地图及角色草稿的真实轮廓精修不在当前资源中宣称完成。

左上角图片显示宽 80、高 54 DIP；标题栏不重复显示品牌文字。未采用的矢量实验保留在本机忽略目录 `tests/artifacts/2026-10-23-real-vector/`。

`franca-taskbar.png` 是为小尺寸简化的纯头像母图：面部更正、色块与五官更集中，减少发丝和高光。`franca-taskbar.ico` 由它打包为 16/20/24/32/40/48/64/96/128/256 像素十种尺寸，供窗口 Icon 与可执行文件 ApplicationIcon 共用。窗口直接加载 ICO（保留 IconBitmapDecoder 的多帧信息），不再让 WPF 从大 PNG 临时缩放原生图标。左上角仍使用原 `franca-pixel.png` 组合图。

小图标最终提示词：以旧纯头像为编辑目标，正面圆脸、蓝发、闭眼、小笑嘴、A/中发卡，放大脸部、减少发丝与高光，使用少量大色块，透明背景、无地图、无外发光。内置图像生成工具编辑美术，Pillow 打包 ICO 尺寸；不把生成素材称为逐像素人工精修。

上一版纯头像素材已归档到本机忽略目录 `tests/artifacts/2026-10-23-taskbar-icon/superseded/`，当前产品资源只保留使用中的图形及其母图。
