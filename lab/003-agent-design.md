# 设计记录 003：桌面原型的职责

记录起点：2026-10-08；2026-10-23 按当前源码修订，删除云端规则下发、未知引擎 OCR 替代及框架迁移安排。

当前原型使用 C# / .NET 9 / WPF。游戏扫描、引擎文件特征判断、安装版本选择和端点选择主要依赖本地代码规则；翻译可调用网络服务或自建端点。

| 工作 | 实际入口 | 限制 |
|---|---|---|
| 游戏发现 | Steam 安装清单 | 目前只支持 Steam 游戏库；非 Steam 游戏未接入 |
| 引擎识别 | EngineDetector 签名表 | 签名匹配不是翻译兼容性结论 |
| 运行时安装 | GameTranslationService / TranslationInstaller | 只提供 Unity 路径，需逐游戏验收；会写游戏目录 |
| 译文请求 | RelayServer / TranslationProviders | 依赖端点和文本可处理性，可能失败或超时 |
| 状态展示 | 游戏库、状态页、日志、悬浮窗 | 展示当前观测，不能证明游戏内完整翻译成功 |

没有云端适配数据库、自动适配新引擎、OCR 或社区分发功能。当前职责和调用边界见 `docs/SYSTEM-MAP.md`，验证范围见 `docs/COMPATIBILITY.md`。
