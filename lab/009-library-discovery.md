# 开发记录 009：Steam 图标、搜索与翻译需求排序

日期：2026-10-21

## 游戏库行为

游戏名称左侧显示从本机 Steam 缓存读取的 24px 图标。支持 App ID 子目录中的 `icon.*` / SHA-1 文件名、旧式 `{appid}_icon.*`，并可回退到 Windows 中注册的 Steam 游戏图标路径。图像缩小加载后冻结，避免后台扫描与 UI 跨线程错误；文件缺失、损坏或不是方形时使用通用游戏图标。

“优先显示需要翻译的游戏”默认开启并保存到设置。已确认具备当前目标语言官方支持的游戏在最后，其余游戏中 Unity 优先，每组按原名排序。未知支持情况不被隐藏，也不当作已确认支持；切换目标语言时不使用旧语言的结论。关闭开关后恢复完整名称排序。

搜索框位于名称列上方，匹配原名、译名或 App ID；支持忽略大小写、重音、多关键词与清空。列表与匹配数量随搜索实时更新。图标、排序和搜索均不修改游戏文件。

## 语言支持数据修正

原来的名称解析在“原名无需翻译”时会提前返回，导致英文和本地文字名称的游戏没有官方支持信息。本次在该路径保留名称原样，同时按七天缓存策略查询语言支持；英文响应直接复用，避免重复请求。

Steam 商店的本地化名称不等于游戏内支持对应语言，因此只使用 `supported_languages` 的查询结论。缓存版本由 7 升为 8，旧版推断需要重新查询；查询失败时旧推断清为未知，不会错误地把游戏排到官方支持区。完整 Auto 模式的约束和实现顺序见 [优化日志](../docs/OPTIMIZATIONS.md)。
