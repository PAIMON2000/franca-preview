# 实验记录 002：端点选择的设计依据

记录起点：2026-10-08；2026-10-23 按实际实现修订。本文件保留设计动机，不作为服务费用、可用性或响应时间承诺。

- 初始目标语言可根据本机语言选择，用户可以修改。系统语言不一定代表个人阅读偏好。
- 端点健康检查与翻译调用共用生产协议；自动选择包含探测、取消和切换迟滞。测量只反映当时网络与短请求，不能保证后续翻译成功或固定耗时。
- 主用失败时按中继策略尝试其他可用端点；失败也可能保留原文、等待重试或显示错误，取决于游戏插件的处理方式。
- 词典和包缓存只包含已有条目；未命中时能否翻译取决于已配置服务。
- API 的费用、额度与访问条件由服务商决定。删除旧记录中的固定免费额度，避免将历史信息当作当前权益。
- 没有云端适配数据库、服务端规则下发或免发版更新端点的能力。端点协议的变更仍需修改和验证客户端代码。
