# 实验记录 004：当前译文缓存格式

2026-10-23 依据 `src/Franca/Services/PackStore.cs` 重写，取代 2026-10-08 的格式草案。旧草案中的 pack.toml、编辑校对、上下文元数据、编译器、三方合并及社区回传没有实现，已删除；当前格式不称为冻结的分发协议。

## 目录与身份

默认保存在程序目录：

```text
packs/<positive-appid>/<target-language>/entries/<hh>.jsonl
```

App ID 必须大于零，语言码需通过当前校验。查找键 `h` 是原文 UTF-8 字节的 xxHash64 小写十六进制，按前两位分片；它用于查找，不是来源认证或内容授权证明。

## 实际写入字段

| 字段 | 当前含义 |
|---|---|
| h | 原文的查找键 |
| src / tgt | 原文 / 译文 |
| st | 当前写入固定为 draft，不代表经过人工审校 |
| by | 调用方传入的来源标识 |
| ts | 写入时的 Unix 秒时间戳 |
| gv | 当前为空，中继未识别并绑定游戏版本 |
| retry | 可选布尔值，标记待重试记录；空译文不作为命中 |

缓存条目以 JSONL 追加，读取时同哈希后加载的记录覆盖先加载的记录；单行损坏会跳过。缓存按 PackStore 实例保存内存分片。枚举非空 src/tgt 供 GameTextSyncService 输出游戏 Franca.txt，尚无通用翻译包编译器。

## 能力边界

- 只有实际捕获并成功处理过的文本可能存在，不能由通关或条目数推断完整覆盖。
- 当前查找没有说话人、上下文或游戏版本维度；同一字符串可能在不同语境下需要不同译法，游戏更新后也需重新验证。
- 没有审校状态流转、签名认证、导入导出界面、自动版本合并或社区分发；也没有统一内容许可。
- 保留原文、缓存命中或散列一致都不构成可分发或翻译质量合格的结论。

相关实现与验证入口见 `architecture.json` 的 relay-provider-pool-pack-cache；当前游戏验证结果见 `docs/COMPATIBILITY.md`。
