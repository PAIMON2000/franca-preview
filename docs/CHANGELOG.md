# 更新日志

## 2026-10-26（未发布）

### 变更

- 东方 Project 补丁数据（`base_tsa`）改为运行时下载：仓库只保留文件清单与哈希（固定上游 commit），首次启用时从上游镜像联网获取约 1 MB 并逐个校验 SHA-256；不再随仓库分发上游内容

## 2026-10-23（未发布）

### 新增

- **内置词典与高速/质量双模式**（设计见 `lab/010-dictionary-dual-mode.md`）
  - 全局跨游戏词典：内置约 210 条英→中游戏 UI 高频词条；在线翻译成功且原文 ≤30 字符时可沉淀；按长度筛选，不具备人名或语境识别能力，短文本也可能有歧义
  - 高速模式（默认）：词典 → 包缓存 → 在线，词典命中返回本地结果；未禁用优化且包中没有译文时尝试后台在线升级
  - 质量模式：不用词典，包缓存 → 在线
  - 可勾选"生成后不再优化"：词典命中不再发在线请求
- **运行时译文升级链路**：在线译文写入游戏目录 `Franca.txt`，XUnity 配置开启文件重载，尝试在游戏运行时更新译文；Suzerain 特定环境有重载实测，不保证其他游戏的生效方式或延迟；游戏启动前同步包条目到译文目录
- **翻译悬浮窗**（设计见 `lab/011-overlay-status.md`）：置顶穿透小窗，显示当前模式、已处理条数、缓存/词典命中率、在途与失败数；可开关、可拖动、位置记忆。独占全屏游戏不可见，建议无边框模式
- 中继计数器：词典命中、在途、失败数，供悬浮窗展示
- 新探针 `--probe-dictionary`（30 项）；真实游戏重载行为验证记录（`tests/2026-10-23-reload-probe.md`）

### 修复

- 官方支持刷新等待旧任务退出后清缓存，并清除失败短路记录；按钮显示旋转字符，至少 5 秒且任务完成前不可重复点击
- 架构探针的词典改用独立临时目录，避免重复运行读取上次模拟译文导致误报

- 自动端点反复横跳导致游戏译名列被周期性整列重翻：切换迟滞（须快 ≥30% 且间隔 ≥45 秒）；无选中时按测速从快到慢逐个真实探测（修复"最快的候选翻译接口报错即永久卡死"）；自动切换不再使机翻译名缓存失效
- 游戏库大面积灰色占位图标：无安装清单且无 exe 的目录是卸载残留（Steam 同样不列为已安装），扫描跳过；无清单但手动放置的游戏从 exe 提取图标（`ExtractAssociatedIcon`）
- 大量游戏显示未知引擎：商业引擎特征识别扩至 Unreal/Clausewitz/MonoGame/GameMaker/Source 2/RE Engine 等（声明式签名表，纯本地判断）；Unity Mono 放宽（Assembly-CSharp.dll 可被发行商剥离）；自研引擎与工具组件统一标注"自研或未知"（15 语言）

### 文案与范围说明
