# 参与 Franca 游戏测试

欢迎帮忙确认一款游戏、一个版本、一个具体场景。成功、失败和未测试分别填写；几分钟的菜单检查也有价值，正文与长时间游玩可以另行补充。

**[下载 Windows x64 测试版](https://github.com/PAIMON2000/franca-preview/releases/latest)** · **[查看已测游戏及版本](COMPATIBILITY.md)** · **[填写测试反馈](https://github.com/PAIMON2000/franca-preview/issues/new?template=game-test.yml)**

## 开始前

- 优先选择兼容性矩阵已有记录的 Unity 或东方游戏。其他游戏先开 Issue 提供版本和引擎信息；不要自行尝试 UE 手工实验包或绕过“暂未支持”。
- 仅在单机环境测试。备份存档和游戏设置，记录已有模组、加载器及翻译插件；不覆盖来历不明的旧安装。
- 使用独立、可写的 Franca 文件夹。首次运行会释放必要组件；启用会写入选定游戏目录。确认目标游戏，关闭游戏后再启用、停用或修复。
- Franca 免费，翻译服务可能收费、限流或中断。记录所用服务名，无需提供 API Key；待翻译文本会发送给所选服务。

## 一次小范围检查

1. 记录 Franca 版本、Windows 版本、游戏版本或 Steam build、源语言和目标语言。先确认未启用时的游戏显示，并正常退出。
2. 在 Franca 中确认所选游戏与翻译服务，启用后启动游戏。记录菜单的一处原文和译文，有条件时保存相同场景的前后截图。
3. 自愿选择一处正文或动态提示，观察漏译、文字溢出、缺字与换行。没有进入正文就写“未测”，无需加载重要存档。
4. 正常退出并重启，观察同一场景是否仍显示译文；只有画面时写“重启后仍显示”，不要直接推断完全离线或缓存命中。
5. 完全退出游戏后停用翻译，再启动确认原文是否恢复；如愿意，再退出并重新启用检查恢复。发现异常时先保留备份和日志，停止继续写入。

不要求一次完成所有步骤。退出异常、崩溃、加载失败和无法恢复请单独说明，保留出现顺序。不要为取得结果反复启动失败的游戏。

## 提交什么

使用上方反馈表记录版本、场景、步骤和结果。截图注明日期、语言和测试范围；前后对照应来自同一游戏版本和场景。没有截图也可以提交文字反馈。

**提交前检查隐私：**遮挡账号、用户名、个人路径与通知；移除 API Key、Authorization、带密钥的端点 URL。不要上传整个设置文件、翻译缓存、存档、游戏资源或完整备份。日志仅截取必要片段并先脱敏。

反馈提交后由维护者核对，再更新 [兼容性矩阵](COMPATIBILITY.md)；个人测试成功不自动代表其他版本或全游戏可用。完整验收定义见 [测试计划](../tests/test-plan.md)。
