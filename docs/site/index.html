Franca

Windows 游戏翻译桌面原型

说明更新：2026-10-26 · 桌面版本 0.1.0（预览） · 开发与验收中

当前定位

Franca 扫描本机 Steam 游戏库，为部分 Unity 游戏和东方 Project 自研引擎游戏安装或配置翻译运行时，并提供本机翻译中继、端点选择和译文缓存；Unreal 静态适配仍在实验阶段、未开放正式启用。可用范围取决于具体游戏、版本、运行环境和翻译服务，尚不能作为通用游戏翻译工具发布。

已经实现的功能

  • 读取 Steam 安装清单，展示游戏、引擎特征、官方语言支持信息和搜索排序。引擎标签来自文件特征判断，不代表游戏翻译可用。
  • 为 Unity Mono / IL2CPP 安装 BepInEx、XUnity.AutoTranslator 及所需组件，写入配置；提供配置检查、备份修复和加载器文件的停用/恢复。东方 Project 自研引擎走 thcrap 运行时注入：交换 exe 存根、生成 jdiff 补丁，不修改游戏数据包。
  • 本机中继按游戏分别保存译文缓存；支持端点选择、故障转移、短语词典与分段翻译。质量模式也会复用缓存；机器翻译结果未经人工审校。
  • 可配置网络翻译服务与自定义端点；设置页、日志、状态页及翻译状态悬浮窗已实现。悬浮窗的游戏内交互和多 DPI 表现仍待验收。
  • 安装写入前保存清单和原文件备份；异常或取消时尝试回滚，冲突时保留文件并停止恢复。游戏侧提供停用、配置修复和卸载（卸载整体还原到未安装基线）；程序本身从源码构建运行，暂不提供安装包和一键卸载。

使用前需要了解的情况

  • 目前没有社区翻译库、翻译包上传订阅或评分服务，也没有 Steam 商店／创意工坊集成。未实现 OCR 屏幕翻译；Unity 与东方 Project 为正式适配路线，Unreal 仅实验准备、未接启用入口，其他引擎仅识别。
  • 网络翻译会把待翻译文本发送给所用服务，游戏译名和语言信息查询也可能访问外部服务。API Key 在本机明文保存，调用时按协议发送给配置的端点；选择第三方端点前应了解其数据处理方式。
  • 仓库开放源码不代表服务商 API 免费。网页端点可能限流、变更或停止服务；API 费用、额度与使用条件由服务商决定。东方路线的补丁数据在首次启用时需要联网从上游镜像下载（约 1 MB），之后走本地缓存。
  • 断网时只能使用已取得且适用的本地缓存与词典，不能保证文本覆盖、译文准确性或响应时间。
  • 安装和修复会改动游戏目录。第三方模组、游戏更新和文件保护可能影响加载；未实现可靠的反作弊识别和账号保护能力。当前测试面向单机环境，不提供受保护或联机环境的适用性保证。
