兼容范围与依赖

说明更新：2026-10-26 · 以具体游戏和版本的测试记录为依据

识别引擎、安装文件、显示译文和完整游戏验收是不同结果。当前没有“所有 Unity 游戏可用”或其他引擎即将支持的结论。

引擎路径的实际状态

引擎／组件当前实现限制
Unity IL2CPP现有安装器使用上游 Doorstop、BepInEx、XUnity.AutoTranslator 和相关互操作组件。Suzerain 有主菜单/选项页及序章正文中文画面证据；BALL x PIT 完成干净基线安装、英语 → 印尼语菜单与重启缓存闭环。不能由这些记录推断其他游戏、完整剧情或更新版本兼容；未验长时间游玩。
Unity Mono有 BepInEx 5 与 XUnity 安装路径；Potion Craft 完成基线安装、英语 → 印尼语主菜单、缓存复用与停用恢复。未进入存档游玩，长时间稳定性待验。Stardew Valley 为 MonoGame，不能作为该路径的证明。
东方 Project（thcrap 运行时路线）th10/th11 交换 exe 存根并生成 jdiff 补丁，不修改游戏数据包。th11 局内对话、结局、音乐室评论、主菜单与全部下级界面精灵图经用户真机确认；th10 对话与界面确认。补丁数据首次启用时从上游镜像下载（约 1 MB）；符卡名因发行版加密跳过；th06 PKGL 不支持；其余正作未逐款验收。见逐游戏证据。
Unreal（实验适配）实验性静态资源翻译，尚未开放一键启用。已实测《逸剑风云决》的菜单/设置及《歧路旅人2》的少量菜单验证；八方完整译文包尚未完成。限已验证的未加密 pak v11、locres 和数据表结构；图片菜单需单独适配。其他游戏需逐款验证。UE5 尚未验证；IoStore、加密资源和运行时热更新未接入。见逐游戏证据和后续路线图。
Ren'Py、RPG Maker、Godot、GameMaker、MonoGame、Source 2、RE Engine、Clausewitz检测器包含相应文件特征。没有正式翻译适配器；展示标签不等于翻译支持，未安排支持日期。
自研或未知展示未匹配明确签名的结果。没有 OCR 或自动适配的替代路径。
自研原生 Loader独立的 x64 代理与 CoreCLR 引导实验，有构建和隔离验证。真实 Unity 初始化时序未验证，桌面安装器不自动部署。

实际使用的主要组件

  • .NET / WPF：Windows 桌面应用。
  • BepInEx、XUnity.AutoTranslator、Il2CppInterop、Harmony：Unity 加载、文本处理和相关运行时依赖；具体包随安装路径变化。
  • thcrap 运行时（Unlicense）与 Noto Sans SC 字体（OFL）：东方 Project 路线的注入与字形渲染；补丁数据不随仓库分发，首次启用时按清单从上游镜像下载。
  • thtk（BSD）：东方数据包只读解包/提取工具链；二进制随附并保留原始许可。
  • UnityDoorstop：上游加载路径，以及自研 Loader 引导序列的来源。改编代码保留对应许可。

RapidOCR、PaddleOCR、manga-ocr 及其他引擎工具仅列为历史技术调研，未接入当前产品。鸣谢不代表已集成、能够调用或获得第三方背书。
