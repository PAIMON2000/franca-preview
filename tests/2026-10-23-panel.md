用户确认的开发清单见 [面板改进清单](../docs/UI-IMPROVEMENT-CHECKLIST.md)。本记录只保留验证方法、结果和边界；截图、原始日志、服务响应及本机配置不纳入 Git，可按功能索引运行探针重新生成验证产物。

## 实现行为

- 默认直接进入游戏库；原名与译名合并，列表只保留游戏、状态、主操作；异常才显示修复；操作明确为“启动游戏”。再次左键点击已选概览可收起详情，按钮、详情内部和右键不误触收起。
- 端点分组为免费、大模型、BYOK、本地、离线；默认大模型展示 DeepSeek 的保存、删除、测试、设主用及官方平台入口；其他已配置模型保留。
- Key 界面掩码，按用户要求明文保存在被忽略的本机配置；删除后后续请求快照和自动候选不再含该 Key，不影响其他凭证。
- 新增大模型可复制 Agent 配置提示词，粘贴 JSON 校验导入；不执行代码、不自动切换主用。目前支持 OpenAI Chat Completions 兼容协议。
- 设置、状态与端点页高级选项按需展开；六主题兼容最小窗口；相关文案覆盖 15 语言。
- 目标语言下新增第二语言，默认未设置，可清空，两页同步。官方支持状态和优先排序考虑任一语言命中；第二语言不用于翻译请求、译名解析或游戏配置写入。
- 官方支持刷新先取消并等待旧任务结束，再失效支持与元数据缓存，清除失败短路记录。按钮每 100ms 轮换字符，至少 5 秒且当前刷新结束后恢复；重复调用直接返回，界面重绘保留忙碌状态，关闭窗口停止任务和定时器。

## 排障与验证边界

- 首轮架构回归读取默认词典目录，命中上次运行留下的模拟译文，造成请求快照检查误报。两个 Relay 已改为各自的临时词典目录；重复运行验证通过，不修改真实翻译逻辑或用户词典。
- Windows 沙箱的注册表/HttpListener 限制可能使本机探针失败；最终需要这些能力的验证在正常本机权限环境执行。
- 元数据与端点回归使用模拟 HTTP 或处理器；本机 Steam 扫描只读，未启用、修复或启动真实游戏。UI 保存/删除检查使用瞬态设置。
- WPF 渲染主要为 96 DPI，覆盖常规与最小窗口。实际多 DPI、完整键鼠遍历及真实游戏翻译画面仍需实机验收，不由构建、模拟服务或截图替代。
