# Franca 功能测试用例 v0.1

本文定义用例；每轮日期、构建、机器环境及结果见对应日期记录。历史结果保留原执行日期，不代表当前版本全部通过。
执行方式：标注 🤖 的由 AI 自动执行（探针/文件/日志检查），标注 👤 的由人操作 UI 并口述结果。
结果列填：✅ 通过 / ❌ 失败（附现象）/ ⏸️ 阻塞（附原因）/ ⏭️ 跳过。

## 固定测试靶子

UE 静态实验的附加门槛：U01 `--probe-ue-pak` 合成往返及独立 UnrealPak `-Verify`；U02 `--probe-ue-static` 缓存/分段/批量回退/熔断/取消/原包不变；U03 `--ue-inspect` 真实只读盘点及游戏外准备清单核对（在线准备会把选中英文片段发往明确授权的翻译服务）；U04 用户在场放包→画面对照→移除恢复→重启增量。U01–U03 不替代 U04。结果见对应日期记录。

U05 自定义文本表须独立验证：空修改序列化逐字节相等；实际修改后重新解析，全量核对行身份、文本键、未选中行、属性与导出长度；用独有验证标记区分游戏原生语言。手工改表不等于已接入通用 locres/端点准备流程。歧路旅人 2 的范围及画面状态见 [2026-10-26 记录](2026-10-26-octopath2.md)。

U05 的合成回归已并入 `--probe-ue-static`，以 UETABLE 标签输出：空历史建立明确身份、空修改一致、未知历史/截断拒绝、损坏格式缓存修复、缓存续译、目标独有值保留和游戏内输出拒绝。不访问真实游戏或端点；真实准备使用 `--ue-table-prepare[-cached]`，仅在显式授权的提供者范围联网，真实显示另验。
