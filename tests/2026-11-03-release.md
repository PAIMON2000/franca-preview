## 发布流程踩坑与修复（本机环境变化）

1. **`Test-Standalone.ps1` 在 PS 5.1 下 ExitCode 恒为 $null**：`Start-Process` + 流重定向 + 手动 `WaitForExit(timeout)` 后 `$process.ExitCode` 读不到（验证：`-Wait -PassThru` 能读到，5.1 特有），原脚本的 `ExitCode -ne 0` 永真导致必报失败。改为输出内容三查：有 RESULT、无 FAIL、stderr 为空、**最后一行是 PASS**（防中途崩溃）。
2. **`[IO.Path]::GetRelativePath` 在 .NET Framework 不存在**：改手工裁剪前缀。
3. **运行中的旧 exe 锁死构建输出**：本机 GUI 从 `bin/Release` 长开，csproj 改版本后构建静默保留旧 1027 产物，导致健康探针曾误跑旧二进制。流程上应「先关 GUI 再构建」。
4. **`ReleaseUpdateProbe` 版本常量**：发版需同步 `current`/DisplayVersion/equal/older/next_day/invalid_tag（本探针就是用来抓「版本号没同步」的，发版时随 csproj 一起改）。
