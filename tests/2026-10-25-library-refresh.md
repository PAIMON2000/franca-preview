# 2026-10-25 游戏库官方支持刷新

## 现象与定位

用户报告刷新官方支持后游戏不展示。重开标准程序后，Steam 扫描 61 项，实际列表显示 57 款，另 4 项按现有非游戏软件筛选隐藏；没有复现整张列表空白。实际窗口初期只有原名，数分钟后中文名逐步出现，官方支持标记缺失；本机公开 Steam 信息查询发生超时。

源码确认原流程先清空 OfficialSupport 及界面标记，再启动整套译名解析；已有中文名也被 Steam 补查阻塞。旧缓存仍有 60 项官方语言列表证据，但对应 OfficialSupport 已全部清空。不能将此认定为所有游戏被删除或扫描失败。

## 修改

- 官方支持刷新改走专用查询，不调用游戏名机翻；主/第二语言共用官方证据查询服务。
- 失效只清查询时间，保留上次结果；新证据可新增或撤销支持，查询失败可沿用缓存中的语言列表。
- 启动解析前先显示缓存译名和支持证据；可恢复此前刷新擦除的标记，旧版错误推断不作为可靠证据复用。
- 同语言重查不先清空界面标记；语言切换仍清理旧语言状态。
- 缓存命中后的 UI 回调移到锁外，避免 UI 读取缓存与工作线程回调互等。

## 验证

独立及标准 Release 构建零警告零错误；游戏库探针 117 项通过，含新增 5 项缓存立即显示、丢失标记恢复、主/第二语言查询失败保留证据、专用刷新不改译名。已有刷新可增加/撤销支持、语言切换与旧版本不可靠证据拒绝等断言继续通过。导航 69 项通过，含按钮立即禁用、旋转、重复点击和至少五秒的恢复时序。

正常关闭本轮排障启动的 Franca，更新标准 Release 后重开。真实窗口确认 57 款游戏、中文名和按支持情况排序恢复；实际点击刷新，按钮进入忙碌状态时数量与中文名保留。截图见上述目录的 `live/after-startup.png` 与 `live/refresh-busy.png`。不将此当作当前 Steam 在线查询已成功完成的证据；查询超时仍可保留上次结果。

探针使用模拟 Steam HTTP、临时缓存和只读本机扫描；不调用真实翻译端点或写游戏目录。首次受限运行在读取注册表时退出，授权只读扫描后的完整回归通过。输出与截图保存在 `tests/artifacts/2026-10-25-library-refresh/`。本轮沿用前一任务的未提交文档改动，不将其算作本修复。
